# Tools

Вспомогательные скрипты для обслуживания репозитория.

## Структура

- `maintenance/` - одноразовые или редко используемые скрипты для правки/миграции файлов проекта.

Скрипты из этой директории не являются частью runtime-приложения и не используются Kubernetes/Jenkins напрямую, если это явно не указано в их описании.
