# Docs

Документация, протоколы и материалы для ВКР.

## Структура

- `appendices/` - подготовленные приложения к ВКР: Kubernetes-манифесты, Jenkinsfile, JCasC, smoke-скрипт, Grafana и выдержки логов.
- `testing/` - методика комплексного тестирования, протокол проверок и переносимые артефакты запусков.

Перед переносом материалов в финальный документ нужно проверить, что публичные IP, домены, JWT, PAT, пароли и другие чувствительные значения обезличены.
