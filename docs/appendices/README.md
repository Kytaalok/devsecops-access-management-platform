## Что нужно дозаполнить вручную

1. Экспортировать JSON дашборда Grafana и вставить его в приложение Д.
2. Запустить `pytest -q` и внести фактический результат в приложение Е.
3. Запустить Jenkins pipeline и перенести номера сборок, статусы stages и ссылки/имена SARIF-артефактов в приложение Е.
4. Запустить `./infra/scripts/bootstrap_keycloak_and_smoke_test.sh` на стенде и вставить итоговый фрагмент лога с `Failed: 0`.
5. При необходимости обезличить публичные IP, домены, логины и секреты перед вставкой в финальную версию ВКР.
