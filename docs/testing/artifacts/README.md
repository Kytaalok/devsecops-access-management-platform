# Testing Artifacts

Переносимые результаты тестовых запусков, которые можно использовать в приложениях ВКР или прикладывать как доказательную базу.

## Текущие файлы

- `api-pytest.xml` - JUnit-отчёт локальных pytest-проверок Task Manager API.

## Правила

- Не складывать сюда секреты, JWT, PAT, cookies и private keys.
- SARIF/JSON/log-артефакты перед публикацией проверять на чувствительные данные.
- Большие временные отчёты Jenkins лучше хранить в Jenkins artifacts, а сюда переносить только финальные выдержки.
